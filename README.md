# CUHK Psychology Presentation Template

## Overview

A LaTeX Beamer template designed for psychology students at The Chinese University of Hong Kong (CUHK). This unofficial template provides a consistent and professional slide format for academic presentations. A PowerPoint (.pptx) version is also included for users without LaTeX access.

## Features

- **CUHK Psychology Theme**: Custom color scheme and icons tailored for psychology presentations
- **Dual Formats**: Includes both LaTeX (.tex) and PowerPoint (.pptx) versions
- **Easily Customizable**: Modify colors, logos, and layouts to suit your needs
- **Academic Focus**: Designed for conference talks, thesis defenses, and course presentations

## Usage

### LaTeX Version

1. Ensure you have a LaTeX distribution installed (TeX Live, MiKTeX, or MacTeX)
2. Compile `main.tex` with your preferred LaTeX editor
3. Modify the template as needed for your presentation

### PowerPoint Version

1. Open `CUHK_Psychology_Template.pptx`
2. Use the provided slide masters and layouts
3. Replace placeholder content with your own material
